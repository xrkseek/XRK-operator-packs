# XRK Operator Packs

Shareable **XRK-Harness** advanced operator packs (`xrk-agent-pack` zip).

## Download

All pack binaries are attached to **[Releases](https://github.com/xrkseek/XRK-operator-packs/releases)** — not committed to this tree.

Browse / search on the product operators site: [XRK 干员站](https://xrk-operators.pages.dev/).

## Import

1. Install [XRK-Harness](https://xrk.indevs.in/)
2. Download a `xrk-member-*.zip` from Releases
3. In the product: send the zip to the sunflower manager, or `team_import pack=` then `team_ready`

## Layout (Face contract)

Required: `.xrk-agent-pack` · `manifest.json` · `playbook.md`  
Optional: `skills/<id>/` · `workspace/` · `env/SETUP.md`
